## 4. キャッシュ

| 対象 | 確認・対応 |
|---|---|
| GitHub Pages のCDN（max-age=600） | 公開後10分ほどで新しい状態になる。直前に訪問したブラウザは最大10分旧版を表示する |
| Service Worker（v10 → v11） | v11 が有効になると v10 のキャッシュは削除される。Cache Storage に game-pc-guide-v11 だけが残ることを確認 |
| SNS のOGPキャッシュ | 共通の ogp.jpg のまま変更なし |
| Google 画像検索 | 非表示維持の7タイトルの旧画像が残る場合は Search Console の「古いコンテンツの削除」で削除をリクエストできる |
