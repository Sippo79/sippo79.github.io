## 3. キャッシュ

| 対象 | 確認・対応 |
|---|---|
| GitHub Pages のCDN | 公開後10分程度で旧画像URLが404になるか、上の一覧から数件を開いて確認する |
| ブラウザのキャッシュ | 旧画像はHTMLから参照されなくなるため表示には出ない。直接URLを開いたときに古い画像が見える場合はスーパーリロード |
| Service Worker（game-pc-guide-v9 → v10） | v10が有効になると旧キャッシュ（v9）ごと削除される。DevTools → Application → Cache Storage に game-pc-guide-v10 だけが残ることを確認 |
| ルートのService Worker（sippo-pc-v11） | ネットワーク優先のため旧画像は返さない。ただし game-pc-guide のページはこのSWではなく game-pc-guide 側のSWが制御する |
| SNS のOGPキャッシュ | X・Facebook・LINE などは古いOGP画像を保持することがある。トップと数ページを共有プレビューで確認し、Facebook はシェアデバッガーで再取得する |
| Google 画像検索 | 旧画像がしばらく残ることがある。Search Console の「古いコンテンツの削除」ツールで404になったURLの削除をリクエストできる |
| Web アーカイブ等の第三者のコピー | 当サイトからは削除できない（git履歴にも残る。履歴の書き換えは行っていない） |
