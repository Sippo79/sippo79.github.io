            BEGINNER GUIDE

            はじめての方へ：パーツの役割

            パソコンは、役割の違うパーツを組み合わせてできています。まずは CPU → GPU → マザーボード → メモリ → ストレージ → 電源 → ケース → CPUクーラー の順に選ぶと迷いにくいです。画面左（スマホでは上）の一覧で、選び終わったパーツと次に選ぶパーツが分かります。

            CPU
            パソコン全体の計算を担当する「頭脳」。ゲームのfpsの上限や、動画の書き出し速度に効きます。
            GPU（グラフィックボード）
            映像を描く担当。ゲームの快適さに最も大きく効きます。製品（メーカー別のカード）によって長さや電源ケーブルが違います。
            マザーボード
            すべてのパーツをつなぐ土台。CPUの「ソケット」と、メモリの種類（DDR4 / DDR5）が合っている必要があります。
            メモリ
            作業中のデータを置く机の広さ。ゲームなら16〜32GBが目安です。
            SSD・HDD
            データを保存する場所。OSやゲームは速いNVMe SSDに入れるのが一般的です。
            電源ユニット
            各パーツに電気を送る装置。容量（W）に余裕があり、GPUの補助電源ケーブルが足りることが大切です。
            PCケース
            パーツを収める箱。マザーボードのサイズ、GPUの長さ、CPUクーラーの高さに上限があります。
            CPUクーラー
            CPUを冷やす部品。空冷（ヒートシンク＋ファン）と簡易水冷（ラジエーター）があります。
            ケースファン
            ケース内の空気を入れ替えるファン。付属ファンだけで足りることも多いです。
            よく出てくる用語
            ソケット（AM5 / LGA1700 など）
            CPUを差し込む部分の形。CPUとマザーボードで同じでないと取り付けできません。
            チップセット（B650 / B760 など）
            マザーボードの機能の格。同じソケットでも、対応するCPU世代やBIOSの条件が変わります。
            BIOS
            マザーボードの基本ソフト。発売が新しいCPUは、マザーボードのBIOSを更新しないと起動しないことがあります。
            フォームファクター（ATX / Micro-ATX / Mini-ITX）
            マザーボードの大きさの規格。ケースが対応している大きさを選びます。
            VRAM
            GPUに載っている専用メモリ。高解像度・高画質ほど多く必要です。
            M.2 / NVMe
            マザーボードに直接挿す小型SSDの形と通信方式。SATAより高速です。
            12V-2x6（16ピン）
            最近のGPUで使われる補助電源コネクタ。電源側にケーブルが無いと変換アダプタが必要です。
            ハードウェアエンコーダー
            GPUに入っている動画圧縮の専用回路。配信や録画でCPUの負担を減らせます（H.264 / HEVC / AV1）。

            HOW IT WORKS

            5角形グラフのスコアの見方

            どの項目も 0〜100点です。実測のFPSやベンチマーク結果ではなく、構成どうしを比べるための相対値です。材料になる値が足りないときは点数を作らず「評価不可」、一部の値が無いときや推定モデルを含むときは「参考値」と表示します。

            性能の材料：GPU GUIDE の描画性能指数（rasterScore）、PC UPGRADE のCPUゲーム性能指数、各パーツの公式スペック。各項目の配分は上のカードのとおりで、計算式は公開しているJavaScript（pb-score.js）と同じです。

            COMPATIBILITY

            互換性チェックで確認していること

            • CPUとマザーボードのソケット／マザーボードのCPU世代対応とBIOS条件
            • メモリの規格（DDR4 / DDR5）・枚数・最大容量
            • マザーボードとケースの大きさ（ATX / Micro-ATX / Mini-ITX）
            • GPUの長さ・厚さとケースの上限（前面ラジエーター時の制限も）
            • CPUクーラーの対応ソケット・高さ／簡易水冷ラジエーターの取り付け位置
            • 電源容量の余裕・GPUメーカー推奨電源・GPUの補助電源コネクタ・電源の規格と奥行き
            • M.2スロット・SATAポート・ドライブベイ・ケースファンの取り付け数・拡張スロット
            • GPUなし構成で映像を出せるか（内蔵GPUの有無）

            対応 根拠となる値があり条件を満たす　要確認 値が不足・条件付き　非対応 条件を満たさない

            「機種未指定」のパーツは、製品を決めていない目安です。寸法やケーブル本数が決まらないため、関係するチェックは「要確認」になります。

            FAQ

            よくある質問

            5角形グラフの点数は実際のFPSですか？

            いいえ。GPU GUIDEの描画性能指数やCPUのゲーム性能指数などから計算した、構成どうしを比べるための相対値です。ゲーム別のFPSは実測データが無いため表示していません。

            「要確認」と表示されるのはなぜですか？

            判定に必要な寸法・ケーブル本数・BIOSの対応などが確認できていないときに表示します。根拠が無いまま「対応」と表示しないためです。購入前にメーカーの仕様ページで確認してください。

            表示される価格は今の販売価格ですか？

            いいえ。価格比較サイトで手で調べた目安で、いつ時点の価格かも表示しています。同じ型番の「最安値の目安」、同じ容量・同じGPUチップの製品の「同等品の相場」、いつの価格かわからない「おおまかな目安」を分けて表示し、合計とコスパには前の2つだけを使います。実際の価格は販売サイトで確認してください。

            グラフに「N/A」と出るのはなぜですか？

            その項目を計算する材料（パーツや最近調べた価格）が足りないためです。0点ではありません。N/Aの項目は図形を閉じずに点線で示し、評価できた項目どうしの間だけを塗っています。

            作った構成は保存できますか？

            ブラウザ内に保存できます。共有ボタンで作ったURLを開くと、別のパソコンやスマートフォンでも同じ構成を復元できます。ログインは不要です。

            グラボ（GPU）なしでも組めますか？

            内蔵GPUのあるCPU（例: Ryzen 5 5600G）なら組めます。内蔵GPUの無いCPUを選んでGPUを外すと「非対応（映像を出せない）」と表示します。
