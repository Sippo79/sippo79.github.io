HOW TO CHECK

PC構成の調べ方

入力する前に、今のPCの中身を確認する方法です。Windows標準の機能だけで確認できます。

GPU・CPU・メモリを調べる

キーボードで Ctrl + Shift + Esc を押すとタスクマネージャーが開きます。 ［パフォーマンス］タブを選ぶと、左側にCPU・メモリ・GPUが並びます。 それぞれをクリックすると右上に型番が表示されます。

ストレージを調べる

タスクマネージャーの［パフォーマンス］タブに「ディスク」があり、 そこに SSD または HDD と表示されます。 容量はエクスプローラーの［PC］からも確認できます。

電源容量を調べる

電源容量はソフトでは確認できません。PCケース背面や側面パネルを開けた中にある 電源ユニット本体のラベルに「650W」などと記載されています。 BTOパソコンの場合は、購入時の構成表にも記載があります。

分からないときは

無理に調べなくても構いません。空欄のまま診断できます。 確認できない項目は「判定できない」と表示され、 勝手に問題なしとは判断しません。

GPU（グラボ）交換

GRAPHICS CARD

ゲームのFPSに最も影響するパーツ。ゲームが重い原因の多くはここです。

  • FPSを上げたい
  • WQHD・4Kで遊びたい
  • 最新ゲームを快適にしたい
⚙️

CPU交換

PROCESSOR

GPUの性能を引き出せているかに関わります。交換範囲が広がりやすい点に注意。

  • GPUを替えてもFPSが伸びない
  • 配信・録画を同時に行う
  • 動画編集をしている
🧠

メモリ増設

MEMORY

費用が安く効果が分かりやすい改善。8GBなら優先度は高めです。

  • アプリを複数開くと重い
  • ゲーム中に画面が固まる
  • 今8GBしかない
💾

SSD増設・換装

STORAGE

読み込みの速さと容量の改善。HDDを使っているなら効果が大きいです。

  • ゲームの容量が足りない
  • 起動・読み込みが遅い
  • まだHDDを使っている
🔌

電源交換

POWER SUPPLY

単体で速くなるパーツではありませんが、GPU交換時に見落とすと動きません。

  • GPUを交換したい
  • 高負荷時にPCが落ちる
  • 電源が古い・容量が不安
❄️

CPUクーラー交換

CPU COOLER

温度が高いと性能が下がります。動作音が気になる場合にも有効です。

  • ファンの音が大きい
  • CPU温度が高い
  • 長時間プレイで性能が落ちる

UPGRADE vs NEW PC

アップグレードと買い替え、どちらを選ぶか

交換するパーツが増えるほど、アップグレードの利点は小さくなります。 判断の目安は次のとおりです。

状況 おすすめ 理由
GPUだけ交換すれば足りる アップグレード 費用を抑えつつ、目的の性能に届きやすい状況です。
メモリ・SSDの不足だけ アップグレード 費用が安く、効果もはっきり出やすい改善です。
GPUに加えて電源も必要 アップグレード 2点までなら、買い替えより費用を抑えられる場合が多いです。
CPUとマザーボードの交換が必要 買い替えを検討 メモリの交換も伴いやすく、費用が大きく膨らみます。
交換費用の合計が20万円前後 買い替え推奨 新品PCなら全体に保証が付き、相性や作業の手間もありません。

「交換しなくていい」ことも、はっきりお伝えします

このサイトは、パーツを売ることが目的ではありません。 診断の結果、今の構成で足りている場合は「現状維持でOK」と表示します。 また、交換が必要なパーツが多すぎる場合は、アップグレードではなく 買い替えをおすすめします。 必要のない出費を勧めないことが、いちばん役に立つと考えているためです。

FAQ

よくある質問

PCが重いとき、まずどのパーツを交換すればいいですか？
症状によって変わります。ゲームのFPSが出ない場合はGPU、 複数のアプリを開くと重い場合はメモリ、 起動や読み込みが遅い場合はSSDが原因になりやすいです。 診断では入力内容からどれに当てはまるかを判定します。
GPUを交換すると電源も交換が必要ですか？
GPUによります。消費電力の大きいGPUに交換する場合、電源容量が不足すると 起動しない・高負荷時に電源が落ちるといった不具合が起きます。 診断では、交換予定のGPUに対して必要な電源容量の目安を表示します。 あわせて補助電源コネクタ（8pin / 12VHPWR）の形状と本数もご確認ください。
アップグレードと買い替えはどちらが得ですか？
交換が必要なパーツの数と費用によります。GPUだけの交換で済むならアップグレードが 有利ですが、CPU・マザーボード・メモリまで交換が必要な場合は、 費用が新しいPCの購入と変わらなくなるため買い替えをおすすめします。 診断ではこの判断も含めて表示します。
自分のPCの構成が分からなくても診断できますか？
分かる範囲だけで診断できます。すべての項目に「分からない」を選べます。 ただし情報が少ないほど判定できる範囲は狭くなり、その場合は 「判定できない」と正直に表示します。 構成の調べ方はこちらで案内しています。
ノートPCもアップグレードできますか？
ノートPCはGPU・CPUの交換ができません（基板に直接取り付けられているため）。 機種によってはメモリとSSDのみ交換・増設できる場合があります。 このサイトの診断はデスクトップPCを前提としています。
BTOパソコン（ドスパラ・GALLERIAなど）でも交換できますか？
多くのBTOパソコンは一般的な規格のパーツを使っているため、交換できる場合がほとんどです。 ただし一部のメーカー製PCでは、電源やケースが特殊な形状で交換しにくいことがあります。 また、メーカー保証期間中に内部を開けると保証の対象外になる場合があるため、 購入時の保証条件をご確認ください。
