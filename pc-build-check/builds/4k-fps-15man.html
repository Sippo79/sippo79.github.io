Build Points

構成のポイント

予算15万円前後でFPSゲーム向けのPCを組むなら、Radeon RX 9070を中心に、CPUはRyzen 5 5600、メモリ32GB、ストレージ1TB NVMe SSDという構成が扱いやすい候補です。Radeon RX 9070は4K / 2160pでのFPSゲームに狙いを定めたバランスで、価格と性能の折り合いをつけやすいのが特徴です。以下でこの構成の狙いと、購入前に確認しておきたいポイントを解説します。

4K環境も視野に入れた構成です。ゲームによっては画質調整をおすすめします。FPSゲームでフレームレートを重視したい人向けの候補です。 Radeon RX 9070はWQHDゲームを重視する人向けの候補です。価格次第でコスパ重視の構成に入れやすいGPUです。CPUを前世代のRyzen 5 5600に抑え、予算の多くをGPUに回しています。 CPUはRyzen 5 5600、GPUはRadeon RX 9070、メモリは32GB、ストレージは1TB NVMe SSDを目安にしています。

Budget ±5

予算を5万円変えると？

同じFPSゲーム・4K向けで、予算だけを変えた構成との違いです。

5万円下げると（10万円前後・参考価格 約11万円） 5万円下げると妥協するところ
  • GPURadeon RX 9070 → Radeon RX 7600
  • CPURyzen 5 5600 → Ryzen 5 5500
  • メモリ32GB → 16GB
  • GPU性能が目安で約36%下がります
  • CPUが Ryzen 5 5500 に変わります
  • メモリが32GB→16GBに減ります

4Kで遊ぶなら、今の構成を選ぶほうが安心です。（参考価格の差: −約5万円）

10万円の構成を見る → 5万円上げると（20万円前後・参考価格 約20万円） いちばん大きな違いはCPUです
  • GPURadeon RX 9070 → Radeon RX 9070 XT
  • CPURyzen 5 5600 → Ryzen 5 7500F
  • SSD1TB NVMe SSD → 2TB NVMe SSD

主な差はCPUです（Ryzen 5 5600 → Ryzen 5 7500F）。CPUの処理に余裕が出ます。GPUもRadeon RX 9070 XTに上がります（目安で約6%アップ）。（参考価格の差: +約4万円）
